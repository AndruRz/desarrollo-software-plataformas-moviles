# Challenge 01 — Gestor de Contactos

App en React que permite listar, agregar y eliminar contactos, simulando una carga inicial de datos (loader al arrancar), usando los conceptos básicos vistos en clase que luego se aplicarán en Ionic.

## Requisitos del reto

- [x] Mostrar un loader al iniciar
- [x] Cargar una lista inicial de contactos
- [x] Permitir agregar contactos con nombre y teléfono
- [x] Permitir eliminar contactos
- [x] Dividir la app en componentes
